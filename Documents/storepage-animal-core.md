# MURMUR Animal Core

## Short Summary
A lightweight engine for ambient animal narrative text. Watch animals react to the world around them through short, atmospheric action descriptions.

---

## Description

**MURMUR Animal Core** is the companion engine to MURMUR Core, purpose-built for passive animal creatures. While MURMUR Core handles thinking, talking entities, Animal Core handles the ones that don't speak — but still have *presence*.

Rather than dialogue bubbles, animals emit short third-person action text that describes what they're doing or reacting to:

> *The cow moos in sympathy because you look barely holding together.*
> *The llama spits in the general direction of your overpriced shiny toothpick.*

- **Animal-Specific Logic** — Separate detection loop tuned for passive creatures like cows, sheep, pigs, chickens, horses, and llamas.
- **Contextual Placeholders** — Supports `{item}` and `{health}` — animals notice what you're carrying and how rough you look.
- **Narrative Format** — Uses italic third-person descriptions instead of speech bubbles for immersion.
- **Zero Overlap** — Operates completely independently from MURMUR Core. Both can run in the same world without conflict.

---

## ⚠️ Warnings & Clarifications

- **This pack does nothing by itself.** Install the **MURMUR Animal Pack** alongside it.
- **Enable Beta APIs** in your world settings.
- Can coexist with MURMUR Core in the same world — they target different entity types.
- **Requires Minecraft Bedrock 1.21.0+**
